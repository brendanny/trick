# Historical archive

implementations, incomplete designs, or superseded workflows; their presence is
not a statement that a capability has been deprecated. Each page identifies
current guidance where available.

Historical pages keep their original URLs but are excluded from search and the
primary navigation. Start with the [user guide](documentation/Documentation-Home.md)
or [developer guide](developer_docs/Developer-Docs-Home.md) for current guidance.
