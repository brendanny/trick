# How-To Guides

Use these guides to complete a specific task in an existing Trick setup, such
as managing a Python environment, containerizing a simulation, or investigating
runtime performance.

Choose a task in the sidebar. Each guide provides its own prerequisites and
steps. The [FAQ](../faq/FAQ.md) answers common questions about compatibility,
build problems, and Trick's behavior.

If you are starting your first simulation, follow the
[tutorial](../tutorial/Tutorial.md). For an explanation of the simulation
workflow and capabilities, use the
[user guide](../documentation/Documentation-Home.md).
