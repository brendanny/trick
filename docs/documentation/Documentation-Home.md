# User Guide

Use this guide when developing and operating a Trick simulation. It explains
how model code becomes an executable simulation, how to control a run, and how
to use Trick's simulation capabilities and analysis tools.

## Start with a working model

If you are new to Trick, [install it](install_guide/Install-Guide.md) and work
through the [cannonball tutorial](../tutorial/Tutorial.md) first.

For your own project, begin with
[building a simulation](building_a_simulation/Building-a-Simulation.md). The
guide follows the work from model source and compilation through runtime
configuration, data recording, and plotting results.

## Find the right level of detail

Choose a topic in this section's sidebar to learn how a capability fits into a
simulation. The **Reference** tab contains file syntax, configuration settings,
and interfaces such as
[S_define](building_a_simulation/Simulation-Definition-File.md) and the
[variable server](simulation_capabilities/Variable-Server.md).

For a specific task, use the [how-to guides](../howto_guides/How-To-Guides.md).
For common questions about Trick and its setup, see the
[FAQ](../faq/FAQ.md).
